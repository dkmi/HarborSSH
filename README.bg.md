# Harbor SSH за iPhone

[English](README.md) · [Български](README.bg.md)

Нативен SwiftUI SSH клиент за iOS 17+, с интерфейс на английски и български. **По подразбиране: английски**, независимо от езика на iPhone.

## Възможности

- Добавяне, редактиране, изтриване и търсене на запазени сървъри.
- Адрес, потребител и произволен SSH порт.
- Удостоверяване с парола или OpenSSH частен ключ: Ed25519 / RSA, с или без passphrase.
- Импорт на ключ през Files или поставяне със системния бутон Paste.
- Интерактивен xterm-256color терминал с PTY, преоразмеряване, Esc, Tab, Ctrl-C и стрелки.
- Задължителен Face ID при стартиране и след преминаване във фонов режим. Няма резервно отключване с PIN.
- Скриване на интерфейса, докато приложението не е активно; затваряне на SSH връзката при заключване.
- Данните и тайните се запазват в iOS Keychain с `WhenUnlockedThisDeviceOnly` и не се синхронизират с iCloud.
- SHA-256 отпечатък за потвърждение при първо свързване и запомняне на публичния host key. Променен ключ блокира връзката.
- Оригинална икона 1024×1024 в AppIcon asset catalog.

## Избор на език

Превключвателят **EN / BG** е достъпен на заключения екран, в лентата на списъка със сървъри и в терминала. Промяната е незабавна и изборът се запазва на устройството между стартиранията и при заключване. Първото стартиране е на английски. Смяната на езика не прекъсва сесията и не променя запазените данни.

Етикетите, статусите, съобщенията на приложението и потвърждението на ключа на сървъра следват избрания език. Терминалният изход се показва както е получен. Системните диалози на iOS, Face ID и Files могат да следват езиковите настройки на телефона.

## Отваряне и стартиране

1. Отворете `HarborSSH.xcodeproj` с Xcode 26 или по-нов.
2. Изчакайте Swift Package Manager да изтегли зависимостите.
3. В Signing & Capabilities изберете вашия Apple Development Team и при нужда сменете Bundle Identifier.
4. Изберете iPhone с настроен Face ID и натиснете Run.

За Simulator включете Features → Face ID → Enrolled. При подкана използвайте Matching Face. Реалният Face ID трябва да се провери на физически iPhone.

При съобщение за липсващ Metal Toolchain инсталирайте компонента от Xcode Settings → Components или с `xcodebuild -downloadComponent MetalToolchain`.

Проектът е готов за development signing. За инсталиране на физическо устройство и разпространение е необходим подпис с вашия Apple акаунт. Не е включен подписан IPA.

При първо свързване сравнете показания fingerprint с този от администратора/конзолата на сървъра. При легитимна смяна на host key изтрийте профила и го създайте отново. При промяна на адреса или порта при редактиране доверието се потвърждава отново.

RSA удостоверяването в Citadel използва `ssh-rsa` (SHA-1); сървъри, които разрешават само RSA-SHA2, няма да го приемат. За съвременни сървъри използвайте Ed25519 ключ. Не се включват остарели transport ciphers.

## Проверки

Езиковите тестове проверяват английския език по подразбиране, запазването на избора и ресурсите за двата езика. Регресионен тест проверява видимостта на командния ред над помощната лента след 200 реда изход и разширяването на терминала при затваряне на клавиатурата. Останалите тестове покриват Keychain round-trip, парсване на криптиран Ed25519 и RSA ключ, грешен passphrase, интерактивен PTY с парола/ключ, отказ на доверие, променен host key и прекратяване на сесията при заключване.

Интеграционните тестове използват локален Python SSH endpoint, който връща подадените байтове и не изпълнява команди. `HarborSSHTests/Fixtures` съдържа само генерирани тестови ключове, които не бива да се използват за реален сървър.

```sh
python3 -m venv .test-venv
.test-venv/bin/pip install 'paramiko>=3.5,<4'
.test-venv/bin/python HarborSSHTests/ssh_fixture.py
```

В друг терминал, при работещ iPhone Simulator:

```sh
GITHUB_ACTIONS=true xcodebuild test \
  -project HarborSSH.xcodeproj -scheme HarborSSH \
  -destination 'platform=iOS Simulator,name=iPhone 16 Pro' \
  CODE_SIGN_IDENTITY=-
```

`GITHUB_ACTIONS=true` изключва ненужните benchmark зависимости на SwiftTerm 1.13.0. Не е необходимо за нормално отваряне на проекта в Xcode.

`project.yml` позволява регенериране с XcodeGen. Готовият `.xcodeproj` е включен; XcodeGen не е нужен за стартиране.
